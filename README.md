# ReString Pro Website

This is a ready-to-upload static product showcase website for ReString Pro.

## Files
- index.html
- styles.css
- script.js

## Best free deployment option
Use Netlify Drop because it is the quickest free option for a static HTML/CSS/JS site.

## Deploy on Netlify
1. Go to https://app.netlify.com/drop
2. Drag the folder `restring-pro-site` onto the page, or drag this ZIP after extracting it.
3. Netlify will generate a public website link.
4. Optional: rename the site in Netlify settings.
